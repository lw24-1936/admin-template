## 1. 认证与个人（/auth）

| 接口 | 方法 | 所需权限标识 | 说明 |
| ---- | ---- | ---- | ---- |
| /auth/login | POST | 免登录 | 登录，返回 token + user(roles/menus/permissions) |
| /auth/register | POST | 免登录 | 自助注册（默认分配 common 角色） |
| /auth/logout | POST | 登录即可 | 注销（服务端删除白名单） |
| /auth/getUserInfo | POST | 登录即可 | 刷新会话（角色/菜单/权限集合） |
| /auth/updateProfile | POST | 登录即可 | 修改个人资料（自助） |
| /auth/updatePassword | POST | 登录即可 | 改密并强制重新登录（自助） |

> 个人资料与改密属于“用户对自己账号”的自助操作，不参与 RBAC 授权（无需按钮 key）。

## 2. 用户管理（/sysAuthUser）

| 接口 | 方法 | 所需权限标识 | 页面按钮（v-perm 同 key） |
| ---- | ---- | ---- | ---- |
| /sysAuthUser/paginQuery | POST | userInfo:userInfo（菜单） | 查询 |
| /sysAuthUser/addSysAuthUser | POST | sysAuthUser:addSysAuthUser | 新增用户 |
| /sysAuthUser/editSysAuthUser | POST | sysAuthUser:editSysAuthUser | 编辑 |
| /sysAuthUser/deleteById | POST | sysAuthUser:deleteById | 删除 |
| /sysAuthUser/resetPassword | POST | sysAuthUser:resetPassword | 重置密码 |
| /sysAuthUser/assignRole | POST | sysAuthUser:assignRole | 分配角色 |

> **列表排序参数**（`/sysAuthUser/paginQuery` 与 `/sysAuthRole/paginQuery` 通用）：
> 请求体在分页参数之外可带 `sortField`（逻辑字段名，需在该资源白名单内）与 `sortOrder`（asc/desc）。
> 服务端用 `util/query/SortWhitelist` 映射为真实列名后拼入 `ORDER BY`，未登记字段一律忽略并回落默认排序
> （用户默认 `created_time DESC`，角色默认 `id ASC`）；`sortField` 仅允许字母/数字/下划线，
> 含其他字符时在参数校验阶段即返回 `code=400`。
>
> - 用户白名单：`userId / userName / nickName / email / phone / status / createdTime`
> - 角色白名单：`id / roleName / roleKey / createdTime`

## 8. 移动端（admintem-mobile）页面与权限标识对照

移动端不新增接口与权限标识，使用的仍是上表的同一份 `permission_key`：
菜单标识决定「首页 · 我的菜单」清单，按钮/菜单标识决定「首页 · 管理入口」是否渲染。

| 移动端位置 | 使用的 permission_key | 页面/接口 | 无权限时的表现 |
| ---- | ---- | ---- | ---- |
| 登录 `#/login` | 无（公开） | `/auth/login` | — |
| 首页 `#/home` | 无（仅需登录） | `/auth/getUserInfo` | 未登录跳登录页 |
| 首页 · 管理入口「用户管理」 | userInfo:userInfo | 桌面端 `/userInfo` | 入口不渲染 |
| 首页 · 管理入口「角色管理」 | userInfo:roleInfo | 桌面端 `/roleInfo` | 入口不渲染 |
| 首页 · 管理入口「权限管理」 | userInfo:permissionInfo | 桌面端 `/permissionInfo` | 入口不渲染 |
| 首页 · 管理入口「新增用户」 | sysAuthUser:addSysAuthUser（按钮级示例） | `/sysAuthUser/createUser` | 入口不渲染，直接调接口 403 |
| 首页 · 我的菜单 | 菜单类 permission_key 集合 | `/auth/getUserInfo` | 菜单不返回 |
| 我的 `#/mine` | 无（本人数据） | `/auth/getUserInfo`、`/auth/updatePassword`、`/auth/logout` | 未登录跳登录页 |

实测口径：`admin` 可见 4 个管理入口；`test` 仅可见其被授权的 2 个，未授权入口不渲染（详见《06-测试报告》）。
