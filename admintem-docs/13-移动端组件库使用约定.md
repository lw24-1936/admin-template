# 13 · 移动端组件库使用约定

本文件登记四个移动端组件库的**定位、版本红线、组件能力与使用场景**，作为后续移动端项目的选型依据。
原则只有一条：**先看技术栈与端，再选库；不要把 React 库塞进 Vue，也不要把 Vue2 库塞进 Vue3。**

## 1. 四个库速查

| 库 | 官方入口 | 技术栈 | 端 | 组件规模 | 一句话定位 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| **uView 1.x** | https://v1.uviewui.com/ | Vue 2 + uni-app | H5、微信/支付宝/百度/头条/QQ 小程序、App | 60+ | uni-app 生态最完整的"全家桶"：组件 + 工具 + 布局 |
| **Taro UI** | https://taro-ui.jd.com/ | React + Taro | 微信/支付宝/百度小程序、H5 | 30 左右 | 京东 O2Team 的 Taro 多端组件库；Taro 3 用 `taro-ui@next` |
| **Cube UI** | https://didi.github.io/cube-ui/ | Vue 2 | H5 | 40 左右 | 滴滴的 Vue2 移动端库，**手势/滚动**能力突出 |
| **NutUI-Bingo** | https://nutui.jd.com/bingo/ | Vue 3 + NutUI | H5、小程序 | 12 个抽奖组件 | 京东营销抽奖组件库（转盘/九宫格/刮刮乐/红包雨…） |

> 注意：`https://nutui.jd.com/bingo/` 是 **NutUI 生态里的"抽奖"子库**，不是通用 NutUI。
> 通用库是 `@nutui/nutui`（Vue3 H5）/ `@nutui/nutui-taro`（Vue3 Taro），70+ 组件、京东视觉规范。

## 2. 版本红线（最容易踩）

| 库 | 能用 | 不能用 |
| ---- | ---- | ---- |
| uView 1.x | Vue 2 的 uni-app 项目 | **Vue 3 的 uni-app 不能直接装**（`Vue.use` + Vue2 语法） |
| uView 的 Vue3 版 | 社区维护的 **uview-plus**（Vue3 / uni-app） | 官方 v1 文档里的 API 与 plus 版有差异，以 plus 文档为准 |
| Taro UI | React + Taro | Vue 项目不能直接用；Vue 版是社区仓库 `taro-ui-vue` |
| Cube UI | Vue 2 H5 | Vue 3 项目不可用；新项目不建议选（Vue2 生态已停止演进） |
| NutUI-Bingo | Vue 3（H5 / 小程序） | Vue 2、React、uni-app 原生项目不能直接用 |
| NutUI 主库 | Vue3 H5 → `@nutui/nutui@3`；Taro → `@nutui/nutui-taro@3` | 小程序原生（非 Taro）不在支持范围 |

## 3. 组件能力与场景对照

| 场景 | uView 1.x / uview-plus | NutUI 3 | Taro UI | Cube UI | Bingo |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 表单 / 输入 / 校验 | `u-form`、`u-input`、`u-picker`、`u-datetime-picker` | Form、Input、Picker、DatePicker | AtForm、AtInput、AtRadio、AtCheckbox | Form、Validator、Input、Picker | — |
| 列表 / 单元格 | `u-cell-group`、`u-cell`、`u-list`、`u-loadmore` | Cell、List、LoadMore | AtList、AtListItem | —（用原生 + Scroll） | — |
| 弹层 / 反馈 | `u-popup`、`u-modal`、`u-toast`、`u-action-sheet` | Popup、Dialog、Toast、ActionSheet | AtModal、AtToast、AtActionSheet、AtMessage | Popup、Dialog、Toast、ActionSheet | — |
| 导航 / 标签 | `u-navbar`、`u-tabs`、`u-subsection`、`u-steps` | Tabs、Tabbar、Steps、NavBar | AtTabs、AtTabBar、AtSteps | TabBar、TabPan、SegmentPicker | — |
| 数据展示 | `u-swiper`、`u-grid`、`u-tag`、`u-avatar`、`u-empty`、`u-skeleton` | Swiper、Grid、Tag、Avatar、Empty、Skeleton | AtGrid、AtCard、AtAvatar、AtBadge、AtProgress | Scroll、IndexList、RecycleList | — |
| 手势 / 滚动 | `u-swipe-action`、`u-sticky`、`u-back-top` | Swipe、Sticky、BackTop | AtFloatLayout、AtLoadMore（滚动加载） | **Scroll / Slide / Swipe / Pullup / Pulldown / Sticky**（强项） | — |
| 营销 / 抽奖 | — | — | — | — | **幸运大转盘、九宫格、跑马灯、刮刮乐、砸金蛋、老虎机、红包雨、摇骰子等 12 个** |

> 表里只列常用项，完整清单以各库文档为准；不要把这张表当 API 手册。

## 4. 本项目怎么选（结论先行）

| 项目 | 现状 | 后续约定 |
| ---- | ---- | ---- |
| `admintem-uniapp`（Vue3 + uni-app） | 自绘样式，无 UI 库 | **新页面首选 `uview-plus`**（uView 1.x 的 Vue3 版），沿用其 easycom 按需引入；表单/列表/弹层不再手写 |
| `admintem-mobile`（Vue3 + Vant 4） | 已用 Vant 4 | **不重写、不混装**；新增页面继续 Vant，若确需 NutUI 3，按页面整体迁移，禁止同页两套 |
| 新 H5（Vue3，只要浏览器） | — | Vant 4 或 **NutUI 3** 二选一：偏"轻、通用"选 Vant；偏"京东视觉、营销活动"选 NutUI |
| 新 Taro（React） | — | **Taro UI**（`taro-ui@next`）或 NutUI-Taro；二选一 |
| 新 Taro（Vue3） | — | **NutUI-Taro 3** 优先（官方并行维护），不要用 React 版 Taro UI |
| Vue2 老项目维护 | — | Cube UI 只在既有项目里用；新功能不新增 Cube 依赖 |
| 抽奖 / 营销活动 | — | **NutUI-Bingo**（Vue3），不要自己写转盘物理与概率动画 |

## 5. 接入方式（可直接抄）

### 5.1 uview-plus（Vue3 + uni-app）

```bash
pnpm add uview-plus
```

```js
// main.js
import uviewPlus from 'uview-plus'
app.use(uviewPlus)
```

```scss
/* uni.scss */
@import 'uview-plus/theme.scss';
```

```json
// pages.json —— easycom 按需引入，模板里直接写 <u-button>
"easycom": {
  "autoscan": true,
  "custom": {
    "^u-(.*)": "uview-plus/components/u-$1/u-$1.vue"
  }
}
```

```vue
<u-button type="primary" :loading="saving" @click="submit">保存</u-button>
```

### 5.2 NutUI 3（Vue3 H5）

```bash
pnpm add @nutui/nutui@3
```

```js
import NutUI from '@nutui/nutui'
import '@nutui/nutui/dist/style.css'
app.use(NutUI) // 或按需引入，避免全量样式
```

主题用 CSS 变量覆盖（品牌色、圆角），不要改组件内部样式。

### 5.3 Taro UI（React + Taro 3）

```bash
pnpm add taro-ui@next
```

```jsx
import { AtButton, AtForm, AtInput } from 'taro-ui'
```

### 5.4 Cube UI（Vue2，仅维护）

```js
import { Button, Scroll } from 'cube-ui'
Vue.use(Button).use(Scroll)
```

### 5.5 NutUI-Bingo（Vue3 抽奖）

按官方文档引入所需抽奖组件与样式；概率、奖品、次数由**服务端**下发与校验，
前端只负责展示与动画，禁止把中奖概率写死在前端。

## 6. 跨库统一的交互约定

不管用哪个库，以下规则不变（与现有 V2 设计令牌一致）：

1. **触摸目标 ≥ 44×44px**；图标按钮必须有 `aria-label`。
2. **表单**：label 可见、错误就近展示、`aria-invalid` 与错误文案关联；不要只用 placeholder 当标签。
3. **反馈**：加载用骨架/按钮 loading，不用全屏遮罩；成功/失败用轻提示，破坏性操作二次确认。
4. **空态/加载更多**：列表必须有 empty、loading、loadmore 三态；分页或触底加载只选一种。
5. **弹层**：Esc/返回可关闭、焦点不逃逸、打开时锁背景滚动；移动端从底部弹出优先。
6. **滚动**：页面滚动与内部滚动不要嵌套两层；长列表用库的虚拟列表/滚动容器，不手写 `overflow` 套娃。
7. **安全区**：底部固定操作栏必须加 `env(safe-area-inset-bottom)`。
8. **主题**：只用库的主题变量 + 我们的 `--lc-*` 令牌，不在业务组件里写裸色值。
9. **按需引入**：uView easycom、NutUI 按需、Taro UI 具名导入；禁止全量注册拖大包体。
10. **降级**：抽奖/滚动动画在 `prefers-reduced-motion` 下给静态结果。

## 7. 新页面接入检查清单

- [ ] 技术栈与库版本匹配（Vue2/Vue3、React/Taro、uni-app/Taro）
- [ ] 只引入当前页需要的组件（按需）
- [ ] 主题色/圆角走变量，不覆盖组件内部结构
- [ ] 表单、空态、加载、错误四态齐全
- [ ] 底部安全区、键盘弹起不遮挡输入
- [ ] 触摸目标 ≥ 44px，键盘可达
- [ ] 列表滚动只有一层
- [ ] 抽奖类概率与次数在服务端校验
