# 16 · CRUD 脚手架生成器

> 目标：新模块从“目录、DTO、Mapper、Service、Controller、页面、迁移”一次生成，
> 减少重复劳动；**生成物是骨架，不是免审代码**。

## 1. 使用

```bash
# 先输出到临时目录，确认后再复制
node scripts/generate-crud.mjs \
  --spec scripts/generate-crud.spec.example.json \
  --out tmp/generated-notice
```

生成成功后目录内包含 `GENERATED.md` 清单。确认无误后，把 `admintem-backend/`、
`admintem-vue/`、`admintem-docs/` 下的文件复制到仓库对应位置；默认不覆盖已存在文件，
确需重跑加 `--force`。

## 2. spec 字段

| 字段 | 必填 | 说明 |
| ---- | ---- | ---- |
| `module` | 是 | 小写开头，接口前缀/前端目录，如 `notice` |
| `entity` | 是 | Java 实体名，如 `SysNotice` |
| `table` | 是 | 小写下划线表名，如 `sys_notice` |
| `prefix` | 否 | 权限前缀，默认等于 `module`，如 `sysNotice` |
| `version` | 是 | 迁移版本，如 `V1.0.17`；**必须选未占用的版本** |
| `menuParentId` | 是 | 菜单父 ID（现有权限表主键，参照 03 文档） |
| `description` | 否 | 中文模块名，用于注释/菜单/页面标题 |
| `fields` | 是 | 字段数组，至少一个 |

字段支持 `name`（lowerCamel）、`type`（`string/int/long/boolean/decimal/datetime`）、
`label`、`required`、`maxLength`、`query`、`list`、`form`、`textarea`、`example`。

## 3. 生成内容

```text
admintem-backend/.../entity/SysNotice.java
admintem-backend/.../mapper/SysNoticeMapper.java
admintem-backend/.../entity/dto/NoticePageQuery.java
admintem-backend/.../entity/dto/NoticeSaveRequest.java
admintem-backend/.../entity/vo/NoticeVO.java
admintem-backend/.../service/NoticeService.java
admintem-backend/.../service/impl/NoticeServiceImpl.java
admintem-backend/.../controller/NoticeController.java
admintem-vue/src/api/notice.js
admintem-vue/src/views/notice/index.vue
admintem-docs/db/changelog/V1.0.17__add_sys_notice.sql
```

- 后端使用 MyBatis-Plus `BaseMapper` + Lambda 条件，不生成 XML；
- 前端复用 `ProTable` / `FormDialog` / `TableToolbar`；
- SQL 含建表、菜单、`add/edit/delete` 三个按钮权限，**不会自动授权给角色**；
- 查询字段支持字符串模糊、数值等值；分页参数继承 `PageQuery`。

## 4. 生成后必须人工复核

1. **权限标识**：`prefix:prefix`、`prefix:add/edit/delete` 是否符合 05 文档；
2. **菜单父 ID/排序**：`menuParentId` 是否指向正确的系统管理目录；
3. **迁移版本**：是否与现有 `V1.0.x` 冲突；不要修改已发布迁移；
4. **字段类型/长度/索引**：按业务补唯一索引、普通索引、默认值；
5. **业务规则**：唯一性校验、状态机、数据权限 `DataScopeService`、审计动作名；
6. **前端字段**：日期/状态是否应换日期选择器/下拉字典；
7. **测试**：至少补 Service 单测、接口回归、页面手工验收。

## 5. 质量门禁

```bash
npm run test:generator
```

生成器自带单测，覆盖“生成 11 个文件”“默认拒绝覆盖”“ProTable 分页事件”等关键断言；
CI 的文档 job 会执行该测试。
